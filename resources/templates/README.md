# Встроенные схемы — шаблоны строки (F-17)

Файлы схем версии 4 (`"type": "line-template"`, `docs/design/F-17.md`, раздел 2):
те же форматы, что блочные схемы `resources/patterns/`, шаблоном строки. Две
syslog-схемы (RFC 3164 и ISO) — один шаблон `syslog.json`. Имена колонок —
прежние буква в букву (на них стоят правила фильтров).

Пока это ДАННЫЕ: их не устанавливает `BuiltinSchemas` и нет в `resources.qrc`
(перевод каталога и установка — шаг 9). Проверка — `tests/line_template`:
поля на образцах `tests/common/builtinsamples.h`, имена колонок против блочных
схем, конвертер блочной схемы против шаблона на том же корпусе.
