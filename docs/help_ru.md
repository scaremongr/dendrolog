# DendroLog — Краткая справка

Быстрый просмотрщик больших лог-файлов: вкладки с несколькими файлами,
извлечение полей, фильтрация, подсветка и дочитывание «на лету».

> Подсказка: любая горячая клавиша ниже настраивается в **Tools → Settings → Shortcuts**.

---

## Открытие логов

- **Открыть файл(ы)** — `File → Open` (`Ctrl+O`) или кнопка с папкой на панели инструментов. Несколько файлов открываются в одной вкладке и сливаются по времени; такая вкладка называется по первому файлу, например `app.log +2`.
- **Перетащите файлы** в любое место окна, чтобы открыть их.
- **Стартовый экран** — пока нет ни одной вкладки, окно показывает кнопки открытия файлов и сканирования папки, а недавние файлы — ссылками.
- Панель **Directory Scanner** — поиск лог-файлов в папке по расширениям и открытие одного или нескольких сразу (`File → Scan Directory…`).
- **Recent Files** — `File → Recent Files` хранит 10 последних файлов; **Clear Recent Files** очищает список.
- **Закрыть вкладку** — `Ctrl+W`, крестик вкладки или средняя кнопка мыши.
- **Save View As** — `File → Save View As…` (`Ctrl+Shift+S`). Сохраняет именно то, что сейчас видно во view (активные фильтры **и** выбор Log Fields) в **новый** файл. Открытые файлы не перезаписываются.
- Сохранение идёт в фоне: окно остаётся рабочим, прогресс виден в строке статуса, кнопка **Cancel Save** рядом останавливает экспорт. Строки берутся такими, какими были в момент начала сохранения, — фильтрация и прокрутка во время экспорта файл не меняют. Отменённый экспорт оставляет прежний файл результата как был.
- Защита экспорта действует и при обращении к открытому файлу через другой путь или файловую ссылку. Результат заменяет выбранный файл только после успешной записи целиком; при сбое показывается ошибка, а прежний файл результата сохраняется.
- Список расширений (например `log, txt`) общий для открытия, сохранения и сканера — задаётся в **Settings → General**.

## Чтение представления

- **Вкладки** — каждая вкладка независима; фильтры/маркеры свои у каждой.
- **Маркер `›` в желобке** — начало логической записи; зелёный — строки из последнего авто-дочитывания.
- **Плашки справа:**
  - Плашка файла — цвет источника (когда во вкладке несколько файлов).
  - `+N` / `−` — строка длиннее видимой области; клик разворачивает/сворачивает её.
- **Подсветка синтаксиса** — строки, числа, hex, URL, пути, GUID, таймстампы, парные скобки.
- **Перенос по словам (Word Wrap)** — кнопка на панели, `View → Word Wrap` или `Alt+Z` (значение по умолчанию — в **Settings → Appearance**).
- **Размер шрифта** — `Ctrl` + колесо мыши над логом, `Ctrl++` / `Ctrl+-` или `View → Larger Font / Smaller Font`; `Ctrl+0` возвращает размер по умолчанию. Размер запоминается.
- **Строка статуса** — текущая строка и число видимых строк; когда фильтры что-то скрыли — и сколько строк в документе всего (`Line 12 of 5 000 (filtered from 116 384)`).

## Выделение, копирование и действия по контексту

- **Протяжка** мышью выделяет текст; **двойной клик** — умный токен.
- **Двойной клик распознаёт:** строки в кавычках, таймстампы, URL, пути к файлам, hex-литералы, IP-адреса, имена файлов, числа, слова. Подряд идущие разделители выделяются группой; клик по пробелам выделяет только пробелы (без перескока на следующее слово).
- **Расширение выделения с клавиатуры:** `Shift+←/→` — на символ, `Ctrl+Shift+←/→` — на токен/блок.
- **Копировать** — `Ctrl+C`.
- **`Пробел`** — развернуть/свернуть текущую строку (как клик по плашке справа).
- **Правый клик → контекстное меню:**
  - **Copy** — копировать выделение; **Copy Whole Line** — всю строку под курсором.
  - Если выделен короткий фрагмент в одной строке:
    - **Find “…”** — быстрый поиск с панели инструментов (прыжок к следующему совпадению).
    - **Find All “…”** — все строки с ним списком в панели **Search**.
    - **Show Only Lines with “…”** / **Hide Lines with “…”** — добавить правило Contains / Not contains и отфильтровать вкладку. Правило сужает то, что вкладка показывает сейчас: если панель Text Filters описывает фильтр этой вкладки (или оба пусты), правило добавляется в панель, как по Apply; если в панели другие, не применённые к вкладке правила, их не трогают — правило получает только фильтр вкладки.
    - **Highlight Lines with “…”** — добавить маркер в Row Highlighters и окрасить такие строки.
  - **Word Wrap (this line)** — для разворачиваемой строки.
  - **Open Link** — если выделен URL.
  - **Open File / Open Containing Folder** — если выделен путь к файлу.
  - **Use as Time Filter Start / End** — выделенный таймстамп, а без выделения — время строки под курсором.

## Фильтрация

- **Уровень лога** — цветные кнопки на панели (Fatal…Trace), меню `Filters` или `Alt+1…Alt+6`. Нажатая кнопка — «показывать только этот уровень»; можно нажать несколько; если не нажата ни одна, видны все уровни. **Show All Levels** (`Alt+0`) отжимает все.
- **Reset Filters of This Tab** — меню `Filters` или `Ctrl+Shift+R`: разом снимает фильтры уровня, времени и текста с активной вкладки.
- **Диапазон времени** — панель *Time Range Filter*: задайте From/To и Apply. Поля заполнены диапазоном времени лога активной вкладки (с секундами и миллисекундами), а панель показывает этот диапазон и включён ли фильтр. **Whole Log** возвращает в поля весь диапазон. Граница, оставленная на краю лога, остаётся открытой — строки, дописанные в растущий лог, продолжают показываться. Если From позже To, ничего не применяется, и панель объясняет почему. Время строки можно подставить сюда из её контекстного меню.
- **Как читается время строки.** Метка без часового пояса считается локальным временем этого компьютера. Явный пояс учитывается: `Z`, `+02:00`, `+0200`, `+02` вплотную к времени, а также `+02:00`, `+0200`, `UTC`, `GMT` через один пробел (например, `2026-09-20 10:00:00 +0200`). Поэтому `10:00:00Z` и `12:00:00+02:00` — один и тот же момент, и файлы из разных поясов сливаются в одной вкладке правильно. Дробная часть секунд любой длины усекается до миллисекунд (`.1` — 100 мс, `.123456` — 123 мс). Фильтр по времени, таймлайн и панель деталей показывают моменты в локальном времени; текст строки не меняется.
- Панель **Text Filters** — скрывает строки, не подходящие под её правила (Include/Exclude, AND/OR, регистр и regex для каждого правила, опционально привязка к полю). Действует на **активную вкладку** кнопками **Apply** / **Reset**. Чтобы *найти* строки, ничего не скрывая, — панель **Search**, см. раздел **[Text Filters и Search](#text-filters-и-search)** ниже.

## Text Filters и Search

С текстом работают две панели, и отличаются они тем, **что происходит с логом**:

| | **Text Filters** | **Search** |
|---|---|---|
| Что делает | **скрывает** строки, которые не подходят | **перечисляет** подходящие строки; лог остаётся полным |
| Главная кнопка | **▶ Apply** (или `Enter` в правиле) | **▶ Search** (или `Enter` в правиле) |
| Отмена | **⟲ Reset** — вкладка снова показывает все строки | **✕ Clear** — список результатов пустеет |
| Где результат | в самом логе | в списке внутри панели Search; клик прыгает к строке в логе |
| Область | активная вкладка; у каждой вкладки свой фильтр | видимые строки активной вкладки |

Правила в обеих панелях одинаковые, и панели можно использовать вместе: сузить лог фильтром, потом искать в том, что осталось. Галочка **Highlight** в каждой панели дополнительно подсвечивает найденный текст в логе. После Reset / Clear правила остаются в панели — их можно применить снова.

### Правила

Каждое правило — одна карточка:

- **Contains / Not contains** — строка должна (Include) или не должна (Exclude) содержать текст.
- **AND / OR** — как правило связано с предыдущим (у первого правила связи нет).
- **Поле** — по умолчанию `(entire row)` — искать по всей строке; можно ограничить конкретной колонкой схемы Log Fields (работает, когда включён **Filter blocks**). Если выбранной колонки нет в текущей схеме (например, после смены схемы), правило не участвует, и карточка об этом сообщает — оно не ищет молча по всей строке; вернётся колонка — вернётся и привязка. При выключенном **Filter blocks** правило с колонкой ищет по всей строке, и карточка это поясняет.
- **⚙ (шестерёнка)** — доп-опции правила: **Case sensitive** (учёт регистра) и **Regular expression**.
- **Образец цвета** — левый клик выбирает цвет подсветки совпадений правила, правый клик включает/выключает подсветку этого правила. Цвет автоматически подбирается контрастным к теме, но его можно переопределить.

### Как комбинируются правила (AND / OR)

Правила соединяются булевой логикой, одинаково в обеих панелях:

- **AND** («и») — строка должна удовлетворять **обоим** соседним правилам сразу. Пример: `Contains "Timeout"` **AND** `Contains "Disk"` — только строки, где есть *и* «Timeout», *и* «Disk».
- **OR** («или») — строке достаточно удовлетворять **хотя бы одному** правилу. Пример: `Contains "Timeout"` **OR** `Contains "Disk"` — все строки с «Timeout» **плюс** все строки с «Disk».
- Приоритет: **AND связывает сильнее OR**, то есть `A AND B OR C` читается как `(A AND B) OR C`.
- **Not contains** удобно комбинировать через AND: `Contains "error"` **AND** `Not contains "timeout"` — ошибки, кроме таймаутов.
- Новое правило связывается через **AND** в Text Filters (сузить) и через **OR** в Search (найти и это тоже). Связь всегда можно поменять вручную.

> Если несколько правил дают пустой результат — почти всегда причина в том, что они соединены **AND**, а искомые тексты находятся в **разных** строках (пересечения нет). Переключите связь на **OR**, чтобы увидеть объединение.

### Панель Search

В панели рядом и запрос, и результаты. Снизу окна (по умолчанию) или в отдельном окне правила слева, результаты справа; если пристыковать панель сбоку, где она узкая, результаты уходят под правила.

- Поиск охватывает **все видимые строки** активной вкладки, включая конец больших файлов; фильтры уровня, времени и текста вкладки по-прежнему ограничивают область поиска. Большие индексные логи просматриваются в фоне без загрузки всего текста в память. Во время поиска список показывает прогресс, после завершения — число совпадений.
- Клик по результату (или переход по списку стрелками) прыгает к этой строке в логе; фокус остаётся в списке.
- Результаты живут вместе с активной вкладкой: строки, дописанные в растущий лог, проверяются по мере поступления и добавляются в список — весь файл заново не просматривается; строку, которую ещё дописывали, проверят снова, когда она завершится. Изменения самого видимого набора — фильтры уровня, времени или текста, перезагруженный файл — запускают поиск заново. При смене вкладки поиск идёт по новой вкладке. Пока панель скрыта, такой полный поиск ждёт её появления.
- **Find All** отправляет сюда одно слово: кнопка **All** рядом с полем поиска на панели инструментов (`Ctrl+Shift+F`) или пункт **Find All “…”** в контекстном меню лога заменяет правила одним правилом `Contains` и ищет. `Ctrl+Shift+F` при пустом поле поиска просто открывает панель с курсором в первом правиле.

### Регулярные выражения

Галочка **Regular expression** трактует текст правила как **регекс в стиле Perl/PCRE**, а не как шаблон с подстановочными знаками командной строки:

- `*` — повтор предыдущего символа, а **не** «любые символы». Чтобы задать «любые символы», пишите `.*`.
- `.` — любой один символ; `\d` — цифра; `\d+` — одна или несколько цифр.
- Правило срабатывает, если выражение найдено **где угодно** в строке (якорь не нужен).
- Примеры: `entry number \d+` найдёт «entry number 42»; `Log entry number .*` найдёт любую такую запись; `(WARN|ERROR)` — строки с любым из двух уровней.
- **Неверное выражение** подсвечивается: поле обводится красным, под ним появляется текст ошибки с позицией. Пока выражение неверно, правило не участвует ни в фильтре, ни в поиске.

### Профили

Комбобокс **Profile** + кнопка **⋯** сохраняют наборы правил под именами (**Save**, **Save as new…**, **Rename…**, **Delete**). У Text Filters и Search профили свои. При переключении профиля с несохранёнными правками программа спросит, сохранить ли их.

## Подсветка строк (Row Highlighters)

- Панель *Row Highlighters* — недеструктивно красит строки целиком по совпадению с паттерном (строки **не** скрываются). Apply/Reset действуют на активную вкладку.

## Схемы полей (Log Fields)

- Панель *Log Fields* — задайте **схему** (упорядоченные блоки: таймстамп, уровень, число, текст, regex, остаток строки…) через **Manage…** или `Tools → Field Schemas…` (авто-определение по строке-образцу или импорт Grok-выражения).
- Галочка **Filter blocks** показывает только выбранные блоки; выбор учитывается в **Save View As** и в текстовых фильтрах, привязанных к полям.

## Быстрый поиск по строке (панель инструментов)

- Поле поиска на панели инструментов — это разовый поиск по тексту (не путать с панелью **Text Filters** выше). `Ctrl+F` ставит фокус в него; `Enter` / `F3` — следующее совпадение, `Shift+F3` — предыдущее (то же — кнопки-стрелки рядом). **Aa** включает учёт регистра. Найденная строка разворачивается, термин подсвечивается. Поиск идёт в фоне, и окно не замирает даже на огромном логе без совпадений: у долгого поиска в строке статуса виден прогресс, `Esc` в поле поиска его отменяет, а ненайденный термин окрашивает поле в красный и отмечается в строке статуса.
- Чтобы увидеть сразу все строки с термином, нажмите **All** рядом с полем (`Ctrl+Shift+F`): панель **Search** перечислит их, ничего не скрывая (см. выше). В панели Search можно задать и несколько правил сразу.

## Дочитывание файлов

- **Reload** — `F5` или кнопка на панели: дочитывает добавленное в конец содержимое.
- **Авто-дочитывание** — тогл рядом с Reload, `File → Auto-reload This Tab` или `Ctrl+Shift+F5` (правый клик по Reload тоже работает); для каждой вкладки своё. Вкладки с авто-дочитыванием отмечены значком. Интервал — в **Settings → General**.
- **Follow tail** — тогл со стрелкой вниз или `Shift+F5`: держит в виду самые новые строки; прокрутка вверх его выключает.

## Directory Scanner

- Кнопка с папкой выбирает каталог и сканирует его на файлы с нужными расширениями; в дереве видны число записей, диапазон времени, счётчики W/E/F и размер. Подкаталоги раскрываются по требованию.
- Имена сортируются **без учёта регистра** и «естественно»: `log2` идёт перед `log10`. Клик по заголовку столбца меняет сортировку (имя — по возрастанию, числовые столбцы — сначала по убыванию).
- **Кнопка ⟳ — обновление.** Клик перечитывает каталог, но не весь: заново разбираются только новые и изменившиеся файлы, а дописанный в хвост лог дочитывается с прошлой позиции (если файл не переписали целиком). Удалённые файлы уходят из дерева.
- **Правый клик по ⟳** выбирает режим обновления:
  - **Вручную** (по умолчанию) — дерево не меняется само, но при изменениях на диске кнопка подсвечивается: «есть что подтянуть».
  - **Автоматически** — изменения приезжают сами; период задаётся тут же в пункте «Auto-refresh interval…». Пока панель скрыта, обновление откладывается до её показа.
  - **Отключено** — ничего не отслеживается; кнопка по-прежнему обновляет по требованию.
- **⚙ раскрывает фильтры.** Фильтр по содержимому читает файлы в фоне; прогресс считается **в байтах**, поэтому полоса отражает реальный ход даже когда один файл на порядки больше остальных. Повторное применение того же запроса берёт результат из кэша (мгновенно), а включённый фильтр по датам сужает круг читаемых файлов.

## Панели и компоновка

- Панели включаются из меню **View** или клавишами `Ctrl+F1…F9` (Text Filters, Directory Scanner, Time Filter, Log Fields, Row Highlighters, Timeline, Search, Entry Details, Statistics). Положение панелей запоминается между сессиями; `View → Reset Panel Layout` возвращает раскладку по умолчанию.
- Длинные списки в панелях Text Filters, Row Highlighters и Log Fields прокручиваются, а не растягивают панель за край окна.
- Панель **Search** показывает правила и результаты рядом, если пристыкована снизу, и друг под другом — если сбоку.

## Настройки и тема

- **Tools → Settings** (`Ctrl+,`):
  - **General** — расширения для сканера, интервал авто-дочитывания, большие файлы.
  - **Appearance** — моноширинный шрифт и размер (живой предпросмотр), перенос по словам по умолчанию.
  - **Colors** — цвета уровней, синтаксиса, выделения и интерфейса.
  - **Shortcuts** — переназначение любой команды; кнопка ⊗ в поле снимает сочетание, **Restore Defaults** возвращает стандартные. Сочетание, отданное двум командам, подсвечивается красным, и OK не принимает настройки, пока конфликт не устранён.
- Окно автоматически следует светлой/тёмной теме Windows.
